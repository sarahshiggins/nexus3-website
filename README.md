# Nexus3 Website

Public mirror of the Nexus3 website.

- `index.html` is the current production website entrypoint.
- `assets/`, `favicon.png`, `llms.txt`, `robots.txt`, and `sitemap.xml` support the current site.
- `v2.html` through `v11.html` are retained historical design explorations.

The canonical production repository is `Nexus3Capital/nexus3-website`; its approved production state is mirrored here without the old preview password gate.

Live site: https://nexus3.ai
